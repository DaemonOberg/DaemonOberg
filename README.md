## ⭐ My Favorite Project

### 🌤️ [Weather App](https://github.com/DaemonOberg/weather-app-exam)

A Flask-based weather application built during my programming studies.

This is my favorite project so far because it gave me the opportunity to challenge myself and improve my understanding of Python, API integration, error handling, and automated testing.

**Key features:**
- Current weather and three-day forecasts for five Swedish cities
- Interactive temperature charts using Plotly
- Weather data from the Open-Meteo API
- Input validation and error handling
- Automated testing with pytest and mocking
- Test-driven development (TDD) using RED, GREEN, and REFACTOR

**Technologies:** Python, Flask, Jinja2, Requests, Plotly, pytest, HTML & CSS
